# SWYNEX--Sales-Interactive-Dashboard

 Overview
 ----------

This project is an Interactive Sales Performance Dashboard built using Power BI as part of Task 3 of my Data Analytics Internship with SWYNEX Technologies. The dashboard analyzes sales data and presents key business insights through KPIs, charts, and interactive filters.

 Objective
 ----------

To build a professional, interactive dashboard that clearly communicates the main findings from the sales dataset, helping stakeholders make data-driven decisions.

🛠️ Tool Used
--------------
Power BI Desktop
📌 Key Features
KPIs
Sum of Revenue: 73.37M
Avg Order Value: 36.69K
Avg Rating: 3.53
Total Orders: 2K
Charts & Visuals
Revenue by Category – Bar chart comparing revenue across product categories (Stationery, Footwear, Electronics, Toys, Grocery, Clothing, Beauty, Furniture)
Monthly Revenue Trend – Line chart showing revenue fluctuation over months
Top 10 Cities by Revenue – Horizontal bar chart highlighting top-performing cities (Pune, Bangalore, Mumbai, Delhi, etc.)
Payment Mode Share – Donut chart showing distribution across Cash on Delivery, Debit Card, Net Banking, Credit Card, and UPI
Interactive Filters
City slicer
Category slicer

These filters allow dynamic exploration of the data across different cities and product categories.

📈 Key Insights
Stationery generates the highest revenue among all categories (10.3M)
Pune and Bangalore are the top revenue-generating cities
Cash on Delivery is the most preferred payment mode (28%)
Revenue shows noticeable monthly fluctuation, peaking mid-year
